# Rental agreement signing page

A single web page for signing a rental agreement on your own phone.

- The agreement is packed into the link you were sent (the part after `#`). Browsers never send that part to a server.
- The page shows the agreement, takes your details and a finger signature, and builds a signed PDF on your own device.
- It has no server, stores nothing and sends nothing. You send the signed PDF back yourself.

Opening the page without a link only shows a note that the link is missing.
